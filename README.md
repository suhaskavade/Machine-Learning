# 📖 About

This repository contains my **Machine Learning learning journey**.

I created this repository to practice and understand the complete Machine Learning workflow from data preprocessing to model evaluation. It includes notebooks, datasets, algorithms, Exploratory Data Analysis (EDA), Feature Engineering, model training, and performance evaluation.

The goal of this repository is to strengthen my Machine Learning fundamentals and build a portfolio of practical projects.
